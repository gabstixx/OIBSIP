# Haven Music Centre

## About the Project

Haven Music Centre is a landing page for a fictional gospel music production and performance centre. The website presents the facilities, services and recording spaces available to gospel artists, choirs and worship teams.

## Features

1. Sticky navigation bar with links to different sections.
2. Hero section with a headline and booking button.
3. About section introducing the music centre.
4. Facilities section showcasing six different spaces.
5. Services section describing the centre's offerings.
6. Featured work and testimonials sections.
7. Contact section with booking information.
8. Responsive layout for desktop and mobile screens.

## Technologies Used

1. HTML5
2. CSS3
