# Personal Portfolio Website

## About the Project

This is my personal portfolio website. It introduces me, highlights my technical skills and showcases some of the projects I have worked on while learning and developing my skills in computer science and software development.

## Features

1. Hero section introducing me and my role as a developer.
2. About section describing my background and interests.
3. Skills section showing my technical skills.
4. Projects section displaying selected projects with links.
5. Contact section containing my contact information.
6. Navigation links for moving between sections.
7. Responsive layout for desktop and mobile screens.

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript
