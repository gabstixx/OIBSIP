# Temperature Converter

## About the Project

The Temperature Converter is a web application that converts temperature values between Celsius, Fahrenheit and Kelvin.

The application allows users to enter a temperature, select its unit and view the converted values in the other temperature units.

## Features

1. Numeric input for entering temperature values.
2. Unit selection for Celsius, Fahrenheit and Kelvin.
3. Conversion between the three temperature units.
4. Display of converted values with their corresponding units.
5. Input validation for empty and invalid values.
6. Error handling for temperatures below absolute zero.
7. Simple and responsive user interface.

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript
